Proposed implementation rules

Lesson progress is stored per account and lesson revision. Completion merges without being undone by replay. The most recently accepted bookmark is used when devices sync; restarting changes the bookmark, not completion. Offline changes wait for reconnection. These conflict rules are proposals for review.

Fixed examples are unmetered and cannot create practice results, fresh random exercises, scores or readiness credit. Starting real training is a distinct action. This demo previews admission only; it never consumes an attempt or minute.

Installed game lessons follow existing offline game access. Generic app/builder help remains available. Resuming a changed lesson revision would restart that lesson with an explanation, preserving prior completion history; this is proposed.
